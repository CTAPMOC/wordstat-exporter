# Wordstat Exporter

Локальное веб-приложение для автоматизированного сбора поисковой статистики из **Яндекс Wordstat** и экспорта результатов в Excel.

Приложение позволяет вставить список поисковых фраз, автоматически обработать их через Wordstat API и получить готовые `.xlsx`-файлы без ручного поиска и скачивания данных.

---

## Возможности

- массовая обработка поисковых запросов;
- интеграция с официальным Yandex Wordstat API;
- экспорт результатов в `.xlsx`;
- отдельный Excel-файл для каждой исходной фразы;
- выгрузка популярных запросов;
- выгрузка похожих запросов;
- отображение прогресса обработки;
- разделение результатов на:
  - успешно обработанные;
  - запросы без статистики;
  - ошибки API;
- автоматический повтор запросов при временных ошибках API;
- отображение примерной стоимости запуска;
- удаление дублирующихся исходных запросов;
- локальная работа без публикации приложения в интернете.

---

## Как это работает

```text
Список поисковых запросов
          ↓
      React UI
          ↓
     Node.js API
          ↓
 Yandex Wordstat API
          ↓
       ExcelJS
          ↓
      XLSX-файлы
```

Для каждой исходной фразы приложение отправляет запрос в Wordstat API, получает поисковую статистику и формирует Excel-файл.

## Настройка Yandex API

Для работы приложения необходимо создать сервисный аккаунт в Yandex Cloud.

Сервисному аккаунту требуется роль:

```text
search-api.webSearch.user
```

API-ключ должен иметь область действия:

```text
yc.search-api.execute
```

Также потребуется ID каталога Yandex Cloud, в котором используется сервисный аккаунт.

---

## Переменные окружения

Создайте файл:

```text
server/.env
```

Содержимое:

```env
PORT=8788

YANDEX_API_KEY=YOUR_YANDEX_API_KEY
YANDEX_FOLDER_ID=YOUR_YANDEX_FOLDER_ID
```

Где:

```text
YANDEX_API_KEY
```

— секретный API-ключ сервисного аккаунта.

```text
YANDEX_FOLDER_ID
```

— ID каталога Yandex Cloud.

> Никогда не публикуйте `.env` и API-ключ в GitHub.

Файл `.env` уже исключён через `.gitignore`.

## Использование

Введите поисковые запросы — по одному запросу на строку:

```text
паспорт безопасности
категорирование объекта
электроизмерения
испытание кабельных линий
```

Выберите необходимые параметры и нажмите:

```text
Начать сбор
```

Приложение последовательно обработает каждую фразу.

## Результаты

Успешно обработанный запрос отображается примерно так:

```text
✓ паспорт безопасности

2000 запросов · 50 похожих

Скачать XLSX
```

Если Wordstat не нашёл статистику:

```text
— очень редкий запрос

Wordstat не нашёл статистику по этой фразе
```

Если произошла техническая ошибка:

```text
✕ запрос

Ошибка Yandex API
```

## Стоимость запросов

В интерфейсе отображается ориентировочная стоимость:

```text
1 запрос ≈ 0,02 ₽
```

Например:

```text
1 запрос     ≈ 0,02 ₽
10 запросов  ≈ 0,20 ₽
100 запросов ≈ 2,00 ₽
```

Это ориентировочная стоимость вызовов Wordstat API и она может измениться при изменении тарифов Yandex Cloud.

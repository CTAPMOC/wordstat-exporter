# Wordstat Exporter

Локальное веб-приложение для массовой проверки поисковой семантики через **Яндекс Wordstat** и выгрузки результатов в единый Excel-файл.

Программа позволяет вставить список заранее подготовленных поисковых запросов, автоматически проверить частотность каждой фразы через Wordstat API и получить готовый `.xlsx` без ручного ввода запросов в Wordstat.

---

## Возможности

- массовая проверка поисковых запросов;
- работа через официальный Yandex Wordstat API;
- один API-запрос для каждой исходной фразы;
- автоматическая последовательная обработка списка;
- получение частотности каждой фразы;
- единый `.xlsx` на весь запуск;
- сохранение исходного порядка запросов;
- отображение прогресса обработки;
- обработка запросов без статистики;
- обработка ошибок API;
- автоматические повторные попытки при временных ошибках;
- удаление дублей из исходного списка;
- предварительный расчёт стоимости запуска;
- локальная работа без публикации сайта в интернете.

---

## Как это работает

```text
Список запросов
      ↓
   React UI
      ↓
 Node.js API
      ↓
Yandex Wordstat
      ↓
 Частотность
      ↓
    ExcelJS
      ↓
Один общий XLSX
```

Пользователь заранее подготавливает нужную семантику, а Wordstat Exporter выполняет одну задачу — массово проверяет её частотность.

---

## Результат

После завершения запуска создаётся один Excel-файл:

```text
wordstat-export-2026-10-06_14-25-00.xlsx
```

Внутри находится лист:

```text
Семантика
```

Структура таблицы:

| № | Запрос | Частотность | Статус |
|---:|---|---:|---|
| 1 | паспорт безопасности объекта | 12 540 | Готово |
| 2 | заказать паспорт безопасности | 843 | Готово |
| 3 | редкий поисковый запрос | 0 | Нет данных |

Запросы, для которых Wordstat не вернул статистику, сохраняются в том же файле со статусом:

```text
Нет данных
```

При технической ошибке:

```text
Ошибка
```

## Требования

Для работы потребуется:

- Node.js 22 или новее;
- npm;
- аккаунт Yandex Cloud;
- сервисный аккаунт Yandex Cloud;
- доступ к Yandex Search API / Wordstat API;
- API-ключ сервисного аккаунта.

```powershell
node -v
```

Проверить npm:

```powershell
npm -v
```

## Установка

Клонируйте репозиторий:

```powershell
git clone <URL-РЕПОЗИТОРИЯ>
```

Перейдите в директорию проекта:

```powershell
cd wordstat-exporter
```

Установите зависимости frontend:

```powershell
cd client
npm install
```

Установите зависимости backend:

```powershell
cd ..\server
npm install
```

---

## Настройка Yandex Cloud

Для работы с Wordstat используется сервисный аккаунт Yandex Cloud.

Сервисному аккаунту необходимо назначить роль:

```text
search-api.webSearch.user
```

Для API-ключа используется область действия:

```text
yc.search-api.execute
```

Также потребуется ID каталога Yandex Cloud.


- количество запросов;

- текущий прогресс;

```text

```

## Стоимость

В интерфейсе используется ориентировочный расчёт:

```text
1 запрос ≈ 0,02 ₽
```

Например:

```text
10 запросов   ≈ 0,20 ₽
50 запросов   ≈ 1,00 ₽
100 запросов  ≈ 2,00 ₽
```

Стоимость является ориентировочной и зависит от актуальных тарифов Yandex Cloud.

---

## Обработка результатов

Успешный запрос:

```text
✓ паспорт безопасности объекта
Частотность: 12 540
```

Если статистика отсутствует:

```text
— редкий поисковый запрос
Wordstat не нашёл статистику по этой фразе
```

При технической ошибке запрос отмечается отдельно и не останавливает обработку всего списка.
